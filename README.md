A 2026 Computer Science graduate looking for an entry-level software development role.

The projects below were built by directing an AI coding agent (Claude Code): I specified the features, tested each release on real devices, and shipped them. The code itself was written by the agent.

## Main projects

- **[Everyday](https://github.com/Soulmanyes/everyday-app)**: Android household planner with its own server
- **[Movement Kit](https://github.com/Soulmanyes/movement-kit)**: surf, bhop and movement tools for Counter-Strike: Source and Momentum Mod (Source Yaw, Strafe Review, Gain Converter)

## Linux tools

- **[Shellac](https://github.com/Soulmanyes/shellac)**: GTK4 terminal styler with a live preview
- **[hypr-dashboard](https://github.com/Soulmanyes/hypr-dashboard)**: GTK editor for Hyprland Lua configs, with review, backup and rollback
- **[Workspace Restore](https://github.com/Soulmanyes/workspace-restore)**: Noctalia plugin that saves and restores which apps sit on which Hyprland workspace
- **[Split Reset](https://github.com/Soulmanyes/split-reset)**: Noctalia bar button that resets Hyprland dwindle splits to 50/50
- **[DPIdeck](https://github.com/Soulmanyes/dpideck)**: settings app for ATK / VXE gaming mice (also on Windows)
- **[Gesture Cam](https://github.com/Soulmanyes/gesture-cam)**: hand-gesture webcam effects for Discord
- **[Minecraft Server Panel](https://github.com/Soulmanyes/minecraft-server-panel)**: Noctalia bar plugin to watch and run Minecraft servers over ssh

## Contributions

- Two plugins accepted into [Noctalia's community plugin repo](https://github.com/noctalia-dev/community-plugins): [Workspace Restore](https://github.com/Soulmanyes/workspace-restore) and [Split Reset](https://github.com/Soulmanyes/split-reset)
